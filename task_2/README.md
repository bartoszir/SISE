# MLP for UWB Indoor Localization (SISE Project)

This project was developed as part of the **Artificial Intelligence and Expert Systems** course. It implements a **Multi-Layer Perceptron (MLP)** to correct UWB-based indoor positioning measurements of a mobile robot.

## Task Overview

UWB (Ultra-Wideband) sensors provide approximate position measurements that deviate from the robot's real coordinates. The goal is to train an MLP that maps **measured (x, y) coordinates** to **real (x, y) coordinates**, effectively learning to compensate for sensor error.

Measurements were collected in two locations within a building: **under hall F8** and **under auditorium F10**. Two types of measurements are available:

- **Static** – robot was placed at each of 225 fixed reference points; used as **training data**
- **Dynamic** – robot moved along a predefined path while measurements were taken; used as **test data**

## Model Architecture

The MLP has a single hidden layer:

```
Input (2) → Hidden (N, configurable) → Output (2)
```

| Component       | Details                           |
|-----------------|-----------------------------------|
| Input features  | Measured x, measured y            |
| Output          | Real x, real y                    |
| Hidden neurons  | Configurable (e.g. 10, 30, 50)    |
| Activation      | Sigmoid / Tanh / ReLU             |
| Optimizer       | Adam (lr = 0.001)                 |
| Loss            | Mean Squared Error (MSE)          |
| Epochs          | 100                               |

Data is **Z-score normalized** using statistics computed from the training set only.

## Data Format

Each CSV file has 4 columns (no header):

| Column | Description                |
|--------|----------------------------|
| 1      | Measured x coordinate [mm] |
| 2      | Measured y coordinate [mm] |
| 3      | Real x coordinate [mm]     |
| 4      | Real y coordinate [mm]     |

## Usage

Run from the `src/` directory:

```
python main.py
```

An interactive menu appears:

```
[1] Create model and run experiment  – prompts for hidden layer size and activation function,
                                       trains a single model, and plots Train/Test MSE curves.

[2] Automated research               – trains all combinations of:
                                         activations: sigmoid, tanh, relu
                                         hidden sizes: 10, 30, 50
                                         seeds:        42, 123, 999
                                       Picks the best seed per configuration, plots learning
                                       curves, and saves a summary to badania_wyniki.csv.

[0] Exit
```

## Research Component

The automated mode (option `[2]`) systematically evaluates 9 model configurations (3 activations × 3 hidden sizes). For each configuration it runs 3 random seeds and retains the best-performing one. Results are saved to `src/badania_wyniki.csv` with columns: activation, hidden neurons, best test MSE, seed.
